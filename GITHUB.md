# Публикация в свой репозиторий GitHub

1. Распакуйте архив и откройте внутреннюю папку pasport-dostupnosti-react в WebStorm.
2. Убедитесь, что package.json, src, server и README.md лежат прямо в открытой папке.
3. Создайте в своём аккаунте GitHub новый пустой репозиторий без автоматически созданных README, .gitignore и лицензии.
4. Скопируйте HTTPS-адрес нового репозитория из раздела Code.
5. В терминале PowerShell из корня проекта выполните по очереди:

```powershell
git init
git branch -M main
git add .
git status --short
git commit -m "Initial React Vite TypeScript SSR application"
$repoUrl = Read-Host "Вставьте HTTPS-адрес своего нового репозитория GitHub"
git remote add origin $repoUrl
git push -u origin main
```

При запросе GitHub используйте свою обычную авторизацию. Если Git попросит имя и email автора, задайте свои данные в настройках Git, затем повторите commit.

Архив не содержит .git и не привязан к исходному Git-репозиторию. .gitignore включён. Исходники можно публиковать целиком: секреты, локальные базы и зависимости в архив не включены.

Чтобы начать разработку:

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

Шаблон .env копируется один раз до настройки своих значений. Команда npm run admin:setup отдельно создаёт пароль для защищённого просмотра заявок; для главной и SEO она не требуется. Существующий .env перезаписывать не нужно. Полные инструкции запуска, проверок и размещения — в README.md.

Загрузка исходников в GitHub и открытие работающего сайта — разные этапы: для SSR, форм и просмотра заявок этому приложению нужен Node.js-хостинг. Инструкции по серверу и необязательному Docker включены в README.md.

В эту версию включена страница /aktualizaciya-pasporta-dostupnosti/ с вложениями. Каталог .update-backups также исключён из Git: в нём могут находиться резервные копии заявок и документов. Для обновления существующей копии сначала остановите сервер и используйте apply-update.ps1. Перед миграцией базы на схему 2 сохраните данные; подробности в UPDATE.md.

Раздел статей включён в исходники. Пользовательские статьи, изображения и заявки находятся в SQLite, исключённой из Git. Перенос исходников на GitHub не переносит рабочую базу: для переезда сайта сохраняйте её отдельно. После обновления зависимостей выполните npm ci.
