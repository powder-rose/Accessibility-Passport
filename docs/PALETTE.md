# Палитра сайта

По правке пользователя от 5 ноября 2026 года бирюзовая и мятная гамма заменена на контрастную нейтральную: графит, серые поверхности и оранжевые акценты. Композиция, контент, фотографии, адаптивная сетка и анимации сохранены.

| Роль                         | Переменная     | Значение |
| ---------------------------- | -------------- | -------- |
| Основной фон                 | --paper        | #f5f5f3  |
| Основной текст и кнопки      | --ink          | #222326  |
| Второстепенный текст         | --muted        | #626469  |
| Серые секции                 | --surface      | #e4e4e1  |
| Светлые карточки и состояния | --surface-soft | #ededea  |
| Более плотные серые подложки | --surface-deep | #d4d5d2  |
| Тёмные секции                | --dark         | #26272b  |
| Текст на тёмном фоне         | --on-dark      | #c5c7ca  |
| Оранжевый акцент             | --accent       | #f57825  |
| Оранжевый текст              | --accent-ink   | #b64818  |

Переменные определены в src/styles/globals.css. Прежние названия teal/mint удалены из действующего кода. Кнопки используют классы button-contrast на светлом фоне и button-light на тёмном. Цвета изменены в исходных правилах; дополнительные слои overrides, inline-стили и !important не добавлялись.

Обновлены стили всех коммерческих страниц, блога, редактора статей, форм и вложений. Сохранены выделения выбранных вариантов квиза, активных вкладок, фокуса и ошибок. Восемь SVG-иллюстраций объектов и favicon перекрашены без изменения геометрии. Изображение для социальных сетей public/images/og-accessibility.webp теперь использует ту же гамму; редактируемый векторный исходник лежит рядом в og-accessibility.svg. Тексты и цена на нём сохранены.

Контраст основных сочетаний по относительной яркости: основной текст на фоне страницы — 14,39:1; второстепенный — 5,42:1; второстепенный текст на серой секции — 4,65:1; светлый текст на графитовой кнопке — 15,71:1; текст тёмной секции — 8,81:1. Это проверка перечисленных сочетаний, а не аудит доступности всего сайта.

Изменение не затрагивает API, SQLite, авторизацию, маршруты, метаданные страниц, sitemap, коммерческие тексты или цены. Зависимости не изменились. Для существующей копии используйте UPDATE.md; для production требуется пересобрать приложение, чтобы выпустить новые CSS и ресурсы.
