# Акт обследования объекта ОСИ

Адрес: /akt-obsledovaniya-osi/. Страница доступна сразу после запуска приложения; отдельного включения в админке нет.

Источник текстов: предоставленное ТЗ «2 АКТ ОБСЛЕДОВАНИЯ ОБЪЕКТА ОСИ.docx». Создание редактора в CMS намеренно пропущено по прямому указанию пользователя. Все коммерческие тексты взяты из ТЗ.

## Реализация

src/content/survey.json хранит специализированный контент. server/service-content.ts подставляет цены из services в src/content/home.json. Изменение цены акта отражается в hero, блоке стоимости, форме, FAQ, title, description и Service/Offer. Полный комплекс использует цену full; цена паспорта и сопровождения берётся из соответствующих услуг.

src/pages/SurveyPage.tsx собирает страницу из небольших компонентов src/components/service/. Шапка, футер, портрет, карточки объектов, квиз, эксперт, FAQ и контактная форма используют общие компоненты сайта. Нормативы, этапы, состав услуги, исходные данные и структура акта имеют отдельные небольшие презентационные компоненты. Поведение и внешний вид главной сохранены. Дополнительные стили вынесены в src/styles/service-page.css и используют существующие CSS-переменные палитры.

Схема маршрутов: src/lib/routes.ts и server/page-data.ts. Новый адрес включён в sitemap.xml. На главной заголовки карточки акта и соответствующего тарифа ведут на новую коммерческую страницу. На странице акта есть хлебные крошки и прямой переход к основной услуге.

## Блочная подача

Нормативная таблица заменена четырьмя карточками. Этапы представлены шестью акцентными блоками. В составе услуги выделен проект акта, остальные восемь пунктов сохранены рядом. Тринадцать исходных материалов распределены по трём смысловым группам без пропусков и повторов; группы используют существующие формулировки. Структура акта представлена тремя отдельными панелями. Сравнение документов и полный комплекс имеют собственные композиции.

Вместо имитации листов документа используется декоративная SVG-иллюстрация доступного входа. Коммерческие тексты, стоимость, порядок разделов и условия услуги сохранены. Весь текст находится в серверном HTML; основные сведения не скрыты за вкладками или аккордеонами. Иконки и графика декоративные, анимации учитывают prefers-reduced-motion.

## Квиз и заявки

Используется общий компонент ExpressCheck, второй копии опросника нет. На странице по умолчанию выбрана услуга survey; вопрос о составе документации можно изменить. Кнопки проверки и карточки объектов передают тот же контекст в общий квиз.

В заявке сохраняются pageUrl, sourcePage, initialService, фактически выбранный service, objectType, UTM, исходные вопросы и ответы. Сервер определяет услугу экспресс-проверки по ответам, поэтому изменение выбора не теряется и исходный survey не подменяет окончательный выбор. Кнопка полного комплекса ведёт на основную услугу с выбранным full.

Подключены общие события commercial_click, express_check_start, express_check_step_N, express_check_submit и lead_submit. Реальный ID Метрики задаётся в site.metrikaId общего файла src/content/home.json; он пока не предоставлен. Контактные данные в события не отправляются.

## Границы услуги и ссылки

По ТЗ сохранено условие: фактическое обследование и измерения организует заказчик, исполнитель предоставляет материалы для сбора сведений и готовит документацию. Исключения из фиксированной стоимости размещены в блоке состава услуги.

Отраслевые коммерческие страницы, актуализация и информационные статьи пока не созданы. Ссылки на них не выводятся. Карточки объектов запускают работающий общий квиз с выбранным типом объекта. После создания новых страниц их адреса нужно зарегистрировать в src/lib/routes.ts и указать в контенте. Пустых ссылок, фиктивных адресов и полного бланка акта для скачивания на странице нет.

## Проверка

npm run check проверяет TypeScript, собирает клиент и SSR-сервер, выполняет 26 автоматических проверок. Тесты новой страницы находятся в tests/survey.test.ts. Мобильная версия и сценарий выбора услуги дополнительно проверены в браузере.
