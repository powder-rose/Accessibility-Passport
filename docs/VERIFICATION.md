## Диагностика блокировки при обновлении

Проверка файлов data в apply-update.ps1 использует FileAccess.Read с прежним FileShare.None; ненужное требование записи удалено. Сообщение теперь содержит полный путь и исходную ошибку, а занятый файл Windows (32/33) отличает от запрета чтения. Проверка по-прежнему выполняется до резервного копирования и замены исходников. Код приложения, зависимости, данные и миграции не менялись. Комплектность архива проверена; PowerShell в среде подготовки отсутствует, исполнение на Windows здесь не проверялось. Прежние результаты 54 тестов относятся к неизменённому коду приложения.
