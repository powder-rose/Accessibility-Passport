## Страница акта обследования ОСИ

- Адрес /akt-obsledovaniya-osi/ отдаёт SSR HTML и HTTP 200, вариант без завершающего слеша перенаправляется 308.
- Блоки идут по ТЗ; восемь типов объектов, шесть этапов, девять элементов услуги, тринадцать исходных материалов, девять частей акта и четырнадцать FAQ проверены.
- Title, description, H1, canonical, Service/Offer, FAQPage, BreadcrumbList и sitemap проверены по исходному HTML.
- Стоимость акта 12 500 ₽ подставляется из общего справочника; проверено изменение тестовой цены во всех зависимых текстах и schema.org.
- Используется один общий шестишаговый опросник; предвыбран акт, услугу можно изменить. Это проверено в браузере и HTTP-тестами.
- Заявки сохраняют исходную страницу, исходную услугу, фактический выбор, UTM, объект и ответы.
- Мобильная компоновка проверена на ширинах 375, 414 и 768 px; горизонтальное переполнение устранено.
- Редактор страницы в админке не создавался по указанию пользователя.
- При визуальной переработке весь контент ТЗ сохранён; SSR-тест дополнительно проверяет исходные материалы, подписи, условия стоимости и цепочку документов. Три группы содержат все 13 материалов ровно по одному разу.
